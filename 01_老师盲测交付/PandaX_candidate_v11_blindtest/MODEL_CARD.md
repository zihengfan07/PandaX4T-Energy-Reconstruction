# candidate_v11 model card

- 训练数据：Run 10972，4499 个有效事件。
- 验证：五个连续完整 `fileNumber` 块，外层测试不参与基础路径、变量层级或正则选择。
- 基础路径：image-derived S1/S2，S1 权重 0.45。
- 模型：三次样条 Ridge，`alpha=0.01`，平滑对数修正上限 `0.10`。
- 输入：64 个位置、漂移、脉冲形状、PMT 图样和事件环境变量。
- 合并 OOF：`sigma_median=0.9973%`，`sigma_worst=1.0427%`。
- 五个外层块中位数：`0.9701%`；五块范围约 `0.859%–0.999%`。
- 核心与尾部：`R68=1.3674%`，`R90=4.2483%`。
- 近修正上限：约 `2.60%`。
- 风险：峰形仍明显非高斯；更丰富的变量可能对 run 状态变化更敏感；尚无独立新 run。
