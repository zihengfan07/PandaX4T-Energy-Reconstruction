# PandaX v12_safe 模型卡

## 模型目的

在不把本底事件假定为某个固定能量的前提下，对 2614.5 keV 标定线进行小幅几何修正，同时抑制跨能区使用时的谱形塑造和人工尖峰。

## 基础能量

只使用稳定的 `qS1ub_C` 与 `qS2Bdesub_C`：

\[
E_0 = 2617.8705\left[
w\frac{qS1ub_C}{m_1}+(1-w)\frac{qS2Bdesub_C}{m_2}
\right],
\]

其中冻结模型取 (w=0.5)，(m_1=11676.6621)，(m_2=611961.688)。任一基础量非有限或非正时直接输出 `NaN`，不做中位数填补。

## 修正参量

- `dt`
- `xS2T_max`, `yS2T_max`
- `xS2B_max`, `yS2B_max`
- 由坐标计算的顶部、底部半径平方

`fileNumber`、`eventNumber`、能量本身以及易失效的图像重建 S1/S2 均不是预测参量。

## 安全策略

- 参量超出训练范围：退回基础能量。
- 模型建议修正过强：退回基础能量。
- 接近修正上限：冻结验证中比例为 0。
- 本底数据仅用于否决会制造尖峰的候选，不作为监督标签。

## 冻结验证结果

- 标定样本 grouped OOF：稳健 (R_{68}) 从 6.473% 降至 6.373%。
- 标定峰拟合中位数：\(\sigma/\mu=4.771\%\)。
- 本底全谱尖峰增长系数：0.997。
- 原异常窗口 1307.5、2600、2887.5 keV 的占比比值：0.986、1.025、0.891。
- 本底修正撞上限比例：0。
- 十个时间段的最大中位能量变化：0.0783%。

## 限制

目前只有一条 2614.5 keV 标定线可用于有标签训练。因此该版本首先解决“不能制造假峰”和“不同时间稳定”的问题，不能据此宣称已证明全能区最优。下一步需要多条已知能量线做独立验证和能量依赖建模。
