# 独立能量重建协议（事件级版本）

更新日期：2026-07-18

## 1. 目标与边界

只从当前 TXT 中的基础观测量建立能量重建，不读取、模仿或反推旧重建代码。当前输入是 run10972 的 4,500 个筛选后标量事件，文件名含 `Egt2MeV`，因此结论只适用于这一固定预选样本。

## 2. 允许的数据

- 信号：`qS1_max`、`qS2B_max`
- 漂移时间：`dt`
- 原始 S2 顶部位置：`xS2T_max`、`yS2T_max`
- 来源元数据：`runNumber`、`eventNumber`，只保留用于追溯
- 内部对齐键：读取后按原 TXT 行序生成 `sourceRow=0,...,4499`

`sourceRow` 只用于表间一一对应；它不是物理变量，不进入响应模型。任何身份字段均不参与模型、折划分、诊断或重采样。

## 3. 候选模型

第一轮只允许低自由度、可解释的处理：

1. 训练侧确定 S1/S2B 的正权重组合；
2. S1 的低自由度漂移时间和半径平方响应；
3. S2B 的表观指数漂移时间趋势和半径平方响应；
4. 对组合能量拟合低阶 `dt+r²` 响应面，必要时再拟合低阶 `x/y` 残差面；
5. 不做事件级残差回归，不使用高自由度三维图，不用能量残差删事件。

## 4. 事件级嵌套 OOF

使用固定种子 10972 对 4,500 个事件做平衡随机五折，每折恰好 900 个事件。对每个外折：

1. 只在其余 3,600 个事件中完成内层方法和参数选择；
2. 用完整外层训练集重新拟合选定方法；
3. 对 900 个测试事件只应用已冻结的变换；
4. 合并五折得到每个事件恰好一次的 OOF 预测。

OOF 只证明该事件未被用于训练其自身预测，不能证明跨 run 或跨采集时期泛化。

## 5. 主评价指标

固定事件集合上优先报告全事件非参数宽度：

\[
R_{68}=\frac{Q_{84.135}-Q_{15.865}}{2Q_{50}},\qquad
R_{90}=\frac{Q_{95}-Q_{5}}{2Q_{50}}.
\]

同时报告固定范围外尾部比例、五个事件折的结果，以及峰中心随漂移时间和半径平方的残余变化。`R68` 与 `R90` 不等同于 Gaussian `sigma/mu`。

参数化峰宽只能在固定窗口、多初值、边界检查和参数 bootstrap GOF 全部通过时作为补充。当前两条优胜谱形均未通过 GOF，因此正式结论仍使用非参数宽度。

## 6. 配对事件 bootstrap

在冻结的 OOF 事件结果上做 1,000 次事件级有放回重采样。同一次复制中 raw 和 corrected 使用完全相同的事件索引。该区间只衡量固定 OOF 结果对事件组成的敏感性，不包含重新训练、模型选择或跨 run 不确定度，并依赖事件可交换假设。

## 7. 正式结论所需的下一步

1. 获得未经过能量阈值预选的数据或明确的选择效率曲线；
2. 确认源类型、源位置、目标能线和 run 配置；
3. 在至少一个完全独立的 run 上冻结验证；
4. 若空间覆盖更均匀，再考虑更细的二维或三维响应图。
