# 下一批数据与信息申请清单

为了把当前的独立重建原型变成可信的物理结果，建议向导师或数据负责人一次性确认：

1. `Egt2MeV` 使用的精确能量估计量、阈值和产生该 TXT 的筛选顺序；
2. 同一 run 未经过能量阈值预选的事件表，至少保留当前基础变量；
3. run 10972 的标定源、源位置、目标峰、运行时间和主要探测器配置；
4. 另一个同类标定 run，作为算法和参数全部冻结后的盲测试集；
5. 若要建立正式空间图，提供空间覆盖更均匀、统计量更大的标定样本；
6. `xS2T_max/yS2T_max` 的有效范围、失败值约定和是否已包含任何位置修正；
7. `dt` 的起点/终点定义，以及 run 内可用的电子寿命独立测量；
8. 能量绝对刻度所需的 `g1/g2B`（或等价 PDE/EEE/SEG）及其适用数据期；
9. cut 标志的 0/1 语义、`finalSS` 的精确定义及每项 cut 的效率；
10. 原始 S1/S2 顶底通道的饱和标记或可靠的线性范围说明。

最关键的是第 1、2、4 项。缺少它们时，可以继续研究算法，但不能排除预选
雕刻和单 run 偶然性，也不能把当前宽度直接作为最终能量分辨率发表。
