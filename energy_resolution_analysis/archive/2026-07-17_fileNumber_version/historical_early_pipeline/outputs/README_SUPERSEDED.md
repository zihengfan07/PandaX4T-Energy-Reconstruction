# Superseded exploratory outputs

These files belong to the early derived-branch exploration and are not the
independent reconstruction result. The original Gaussian+exponential peak model
fails goodness-of-fit checks, the upstream `E > 2 MeV` selection is unknown, and
the development boundary now excludes derived charge branches.

Use `../INDEPENDENT_REPORT.md`, `../channel_physics_outputs/`, and
`../basic_matrix_outputs/` for the current work. The source code has also fixed
an exploratory-bootstrap baseline reference and validation-fit filtering, but
this historical directory is intentionally not used for final conclusions.
