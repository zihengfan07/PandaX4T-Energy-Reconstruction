# candidate_v9 分组嵌套验证结果

## 最终身份

```text
model: spline_ridge_a100_c100_soft
alpha: 100
soft bound: 0.10
transform: 0.10 * tanh(raw_delta / 0.10)
predictor features: 30
grouping key: fileNumber (not a predictor)
```

## 验证设计

- 4499个有效事件，985个采集文件；
- 五个连续完整文件块作为外层测试；
- 每个外层训练池内部再次按完整文件块选择配置；
- 12种预先固定的峰拟合协议；
- 1000次 file-cluster paired bootstrap（\(R_{68}\)）；
- 所有标定、填补、尺度和模型参数只由当前训练侧产生。

## 主结果

五个外层文件块的12协议 \(\sigma/\mu\) 中位数：

```text
current formula: 4.1179%
candidate_v9:    2.6287%
relative gain:   36.16%
```

五个文件块均改善：

| fileNumber范围 | 原公式 | candidate_v9 | 相对改善 |
|---|---:|---:|---:|
| 0-199 | 4.5616% | 2.7978% | 38.67% |
| 200-399 | 4.0356% | 2.4100% | 40.28% |
| 400-599 | 4.4918% | 2.8017% | 37.63% |
| 600-799 | 4.0605% | 2.5737% | 36.62% |
| 800-999 | 4.1179% | 2.6287% | 36.16% |

合并 OOF 的稳健宽度：

```text
R68: 6.7861% -> 3.1123%
R90: 13.0694% -> 6.6932%
```

file-cluster bootstrap 的 \(\Delta R_{68}\) 95%区间：

```text
[-4.0280, -3.4663] percentage points
```

## 七项门槛

- 五个外层块全部改善：PASS
- 最大峰中心偏差不超过0.3%：PASS
- 每块 \(R_{90}\) 不恶化：PASS
- 所有预测有限且为正：PASS
- 靠近平滑修正上限比例不超过5%：PASS
- file-cluster bootstrap上界小于零：PASS
- 固定环境下S1/S2结构单调：PASS

## 与v8的关系

v8的事件级随机交叉验证结果约为1.883%，但存在文件状态泄漏风险、修正上限较大
（0.21）且峰形GOF极差。v9牺牲了部分表面峰宽，换取：

- 完整采集文件隔离；
- 嵌套选参；
- 平滑低容量模型；
- 0.10软修正边界；
- 峰中心、尾部和分簇不确定性约束；
- 更清楚的物理与审计解释。

因此，v9是当前推荐的盲测候选；v8保留为激进模型对照。
