# v18 平滑响应图实验结果

本轮没有继续增加复杂模型，而是将 `dt`、S2 宽度和位置分别建立平滑分箱响应曲线，再将各变量修正相加。共测试 3 组变量、3 种分箱数、3 个收缩强度和 3 个修正上限，共 81 个候选。

开发数据上有 2 个候选通过全部本底安全门。数值最好的候选使用：

`dt + wS2CDF_max + xS2T_max + yS2T_max`

参数为 4 个分箱、收缩强度 0.3、修正上限 0.5%。开发集上：

- `sigma/mu` 相对改善 0.2316%；
- `R68` 相对改善 0.1509%；
- `R90` 相对改善 0.0554%；
- 本底修正覆盖率 89.12%；
- 2600 keV 邻域尖峰指标降至原公式的 0.9488 倍。

但是，在完全未参与选择的最后 900 个事件上：

- 拟合得到的 `sigma/mu` 改善 3.5404%；
- `R68` 反而恶化 0.2138%；
- `R90` 反而恶化 1.0564%。

这说明响应图主要把峰中心变窄，却把更宽的事件尾部变差。按照预先设定的多指标安全规则，v18 留出验证不通过，只能作为诊断实验，不能替代 v15。

当前结论仍是：v15 S10 为数值最优研究候选；进一步可信提升需要新 run 和多个单能峰，而不是继续使用同一批数据增加模型自由度。
