# PandaX-4T 最新数据检查与 v21 结论（2026-08-22）

## 1. 本次重新开始所用数据

- Kr 数据：`bkg_26_8_13/doke_data/kr.root`，787039 个事件，28 个 run。
- 2615 keV 数据：同目录下的 `2615.root`，19036 个事件，run 9563、9566、9698。
- 老师给出的 Doke 参数：
  \[
  g_1=0.128755,\qquad g_{2b}=8.6125.
  \]
- 基础能量严格使用：
  \[
  E_{\mathrm{rec}}
  =0.0137\left(
  \frac{qS1_{\mathrm{PCs}}}{g_1}
  +\frac{qS2Bdes_{\mathrm{PCs}}}{g_{2b}}
  \right).
  \]

`qS1_PCs` 与 `qS2Bdes_PCs` 已经是修正量，因此本工作只允许学习幅度较小的残余修正，不重新训练一个直接输出最终能量的黑箱模型。

## 2. 首先得到的否定结果

在全部 Kr run 上训练统一残差图，并按独立 Kr run 交叉验证时，没有候选模型达到预先规定的 0.1% 改善门槛。因此，不能声称存在一个对全部时期通用的全局残差模型。

2615 数据在基础公式下的拟合结果为：

| 数据 | 峰位 / keV | $\sigma/\mu$ |
|---|---:|---:|
| 全部 | 2658.87 | 2.278% |
| run 9563 | 2701.46 | 2.516% |
| run 9566 | 2725.33 | 2.887% |
| run 9698 | 2640.75 | 1.712% |

三个 run 的峰位漂移远大于相邻 Kr run 的低能峰位漂移，说明主要问题具有明显的时间/run 依赖，不能只用一个全局模型处理。

## 3. 分时段 Kr 修正

只用 Kr 数据选模型，2615 数据不参与模型选择：

- P1：Kr run 9568 学到的图应用于 2615 run 9563、9566。Kr 留出验证选择 **只修正 S2 对漂移时间 $dt$ 的残余依赖**，Kr 的 $R_{68}$ 改善 0.893%。
- P2：Kr run 9685、9695 学到的图应用于 2615 run 9698。Kr 留出验证选择 **同时修正 S1、S2 对 $dt$ 的残余依赖**，Kr 的 $R_{68}$ 改善 0.148%。

所有单项和最终因子均限制在

\[
0.97\leq C(dt)\leq 1.03,
\]

避免过强修正。

## 4. 2615 keV 独立检查结果

| 数据 | 修正前 $\sigma/\mu$ | 分时段 Kr 修正后 | 相对改善 |
|---|---:|---:|---:|
| 全部 | 2.278% | 1.947% | 14.5% |
| run 9563 | 2.516% | 2.218% | 11.8% |
| run 9566 | 2.887% | 2.323% | 19.5% |
| run 9698 | 1.712% | 1.702% | 0.56% |

150 次配对 bootstrap 的相对改善 95% 区间：

- 全部事件：11.7%--17.1%，150/150 次为正；
- run 9563：7.1%--17.4%，150/150 次为正；
- run 9566：12.4%--23.9%，有效拟合中全部为正；
- run 9698：-2.1%--2.4%，不能确认有真实改善。

## 5. 当前必须保留的风险说明

P1 的 2615 数据集中在较低的 $dt$ 区域，22.8% 的事件达到 S2 修正下限 0.97。虽然该方向通过了 Kr 留出验证和 2615 重采样检查，但修正触顶比例偏高。因此，v21 目前应称为 **有希望的时间匹配候选方案**，不应称为最终最优模型。

P2 没有修正触顶，但改善幅度很小，run 9698 的结果与“不改善”仍相容。

此外，Kr 的 41.5 keV 单峰只能约束位置/时间响应，不能单独确定从 41.5 keV 到 2615 keV 的能量非线性。峰位的绝对偏差需要多条已知能量峰建立独立的能量刻度曲线，不能靠本残差图解决。

## 6. 当前结论与下一步

1. 放弃一个覆盖全部时期的统一黑箱模型。
2. 保留基础 Doke 公式，将修正拆为“时间邻近的 Kr 响应图”和“多峰能量刻度”两层。
3. 下一批数据应同时提供：待处理 run、时间相邻 Kr run，以及至少两条以上已知能量峰。
4. 对 P1 增加低 $dt$ Kr 统计，检查 S2 因子在 0.97 附近是否仍应继续下降；在完成该检查前不放宽 $\pm3\%$ 限制。
5. 用新的、未参与任何选择的 run 做最终盲测，报告逐 run 的峰位、$\sigma/\mu$、因子触顶比例和频谱形状。
