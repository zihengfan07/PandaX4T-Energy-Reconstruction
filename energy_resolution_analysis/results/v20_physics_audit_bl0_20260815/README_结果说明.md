# v20 分离式 S1/S2 物理修正审计

## 本轮做了什么

1. 使用前 80% 时间段拟合未经均匀性修正的 `qS1_max` 与 `qS2Bdes_max` 对漂移时间的响应。
2. 按论文思路分别修正 S1 和 S2；最后 20% 时间段完全不参与拟合。
3. 保持当前公式中的 S1/S2 权重不变，形成第一版联合能量。
4. 在 96915 个本底事件上检查能谱、2600 keV 附近结构和分布外事件。

## 得到的物理量

拟合电子寿命为

\[
\tau = 1207.1\ \mu\mathrm{s}.
\]

修正后 S1、S2 的中位响应对漂移时间基本变平，说明响应函数本身有效。

## 为什么当前版本不能部署

- 标定文件由连续谱主导，2614.5 keV 峰非常弱，不能像论文中的 164/236 keV 单能峰那样可靠拟合响应。
- 留出集整体谱形指标变差：`R68` 从 6.54% 变为 7.40%，`R90` 从 13.01% 变为 14.83%。这些是全谱指标，不是单峰分辨率。
- 本底中位能量从 1318.0 keV 移到 1379.3 keV，说明直接沿用原来的 S1/S2 权重会造成明显能标偏移。
- 13.35% 的本底事件位于标定漂移时间拟合范围之外。

因此，本轮输出是诊断模型，不是老师可直接使用的新模型。

## 下一步所需数据

需要至少一组带有明确单能峰并保留原始 S1/S2 的标定数据；最好包含多个能量峰和多个 run。随后才能分别拟合响应、重新确定 `g1/g2`，并进行跨 run 留出验证。
