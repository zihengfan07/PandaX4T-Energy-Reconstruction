# v16--v17 继续提升实验结论

## 做了什么

- v16：比较 4 组变量结构和 4 类模型，共 144 个候选，包括加性 Ridge、二阶交叉项、平滑样条和浅层梯度提升。
- 标定数据按真实时间顺序划分：前 80% 用于模型选择，最后 20%（900 个事件）作为未见留出段。
- v17：将 M06、v15 修正位置模型和顶部位置模型按 5% 步长扫描 231 种非负权重组合。
- 所有实验继续使用本底谱假峰、2600 keV 邻域、能量排序、时间稳定性和修正幅度安全门。

## 主要发现

1. 开发集上最好的交叉项模型显示 0.987% 的相对 \(\sigma/\mu\) 改善，但在留出段反而恶化 1.212%，属于明显过拟合，不能采用。
2. 8 个通过开发集安全门的模型中，只有简单的顶部位置加性模型在留出段通过：
   `dt + wS2CDF_max + xS2T_max + yS2T_max`。
   它在留出段改善 1.363%，但完整五折交叉验证只改善 0.143%，说明效果随时间段变化，尚未稳定。
3. 231 个融合权重中有 19 个通过安全门，但没有任何融合超过 v15 的 S10 模型。
4. 当前完整五折结果仍以 v15 S10 数值最好：\(\sigma/\mu\) 从 4.17809% 降至 4.16604%，相对改善 0.2884%。融合没有继续降低该数值。
5. S10 的全谱最坏局部尖峰增长为 1.0994，距离 1.10 安全阈值非常近；顶部位置模型虽然峰宽改善较小，但本底尖峰指标更稳，并同时改善 \(R_{68}\) 和 \(R_{90}\)。

## 结论

在现有单个 run、单一主要能区的数据条件下，继续增加变量、非线性或模型融合没有产生可信的进一步提升。当前限制主要来自训练信息不足和随时间变化的响应，而不是模型容量不足。v15 S10 保留为“数值最优研究候选”，顶部位置四变量模型保留为“更稳健候选”；两者都不能在没有新 run、多条单能峰盲测的情况下升级为最终模型。
