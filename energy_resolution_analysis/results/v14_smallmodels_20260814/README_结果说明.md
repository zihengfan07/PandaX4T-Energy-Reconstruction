# v14 十个小模型筛选结果

## 数据与验证

- 标定开发样本：Run 10972，共 4499 条有效能量事件；
- 本底安全样本：Run 10972，共 97195 条事件；
- 基础能量固定为给定三次修正 `Energy_cor`；
- `fileNumber` 不作为模型变量；五折 OOF 按真实时间戳 `t` 连续分段；
- 本底不提供能量标签，只用于检查造峰、OOD、覆盖率、排序和时间稳定性。

## 新增的五个因素

1. `qS2channelStdevTo1_max`：历史重要性第 1；
2. `xS2T_max`：历史重要性第 2；
3. `yS2B_max`：历史重要性第 3；
4. `qS1channelStdevTo1_max`：历史重要性第 4；
5. `wS2CDF_max`：历史重要性第 12。

加上 v13 已使用的 `dt`，总共比较 6 个候选因素。没有使用绝对 S1/S2 总电荷，也没有使用曾经产生 `inf` 和事件堆积的 ImageMCPAF 电荷变量。

## 十个模型

- M01：`dt`
- M02：`dt + S2通道离散度比例`
- M03：`dt + x`
- M04：`dt + y`
- M05：`dt + S1通道离散度比例`
- M06：`dt + S2累积分布宽度`
- M07：`dt + x + y`
- M08：`dt + S1/S2通道离散度比例`
- M09：`dt + x + y + S2累积分布宽度`
- M10：全部 6 个因素

所有模型固定 `alpha=1000`，单事件修正上限固定为 `0.25%`，从而只比较变量组合本身。

## 当前筛选结果

共有 2 个模型通过全部安全门槛：M01 和 M06。按五折 OOF 的峰拟合宽度，M06 数值最好，因此被标记为本轮研究候选：

- 变量：`dt + wS2CDF_max`；
- `sigma/mu`：4.17809% -> 4.16627%；
- 相对改善：0.28295%；
- `R68`：6.77414% -> 6.77775%，轻微恶化约 0.05336%；
- 本底真正应用修正：22.80%；
- 本底 OOD：4.16%；
- 强修正回退：76.83%；
- 修正前后排序相关：0.99999835；
- 本底局部尖峰指标增长：6.14%，低于预设 10% 门槛；
- 十个时间段中真正被修正事件的中位修正跨度约 0.0259%；
- 十个时间段的修正覆盖率跨度约 1.82%。

## 关键结论

M06 比 v13 的 `dt` 单变量模型有更明显的峰拟合改善，但改善仍小，同时 `R68` 略有恶化。M10 全变量模型在本底上的 OOD 达到约 39.65%，真正修正率只有约 2.69%，证明把五个因素全部加入并不能提高推广能力。

因此，M06 只能称为“v14 研究候选”，不能替换当前教师演示包，也不能宣称已经解决 2600 keV 或其他能区的分辨率问题。正式升级仍需要多条已知能量峰和跨 run 盲测。
