# v15 多变量搜索结果（2026-08-14）

本轮在 bl-0 上比较了 17 组变量结构、4 个 Ridge 正则强度和 3 个修正幅度上限，共 204 个候选。`fileNumber`、绝对 S1/S2 电荷以及本底能量标签均未作为模型输入。

## 最佳通过安全门的候选

模型：`S10_corrected_position_a3000_c75`

输入变量：

- `dt`
- `wS2CDF_max`
- `yS2Tcor_max`
- `xS2Bcor_max`

参数：`alpha=3000`，最大对数修正幅度 `cap=0.0075`。

结果：

- 标定样本的 \(\sigma/\mu\)：4.17809% -> 4.16604%；相对改善 0.28844%。
- M06 的对应结果为 4.16627%，因此 v15 仅比 M06 好 0.00023 个百分点，差异很小。
- \(R_{68}\)：6.77414% -> 6.77469%，相对轻微变差 0.0082%，仍在预设容差内。
- \(R_{90}\)：13.12198% -> 13.08315%，相对改善 0.2959%。
- 本底事件实际修正比例 69.60%，明显高于 M06 的 23.13%。
- 本底分布外比例 0.52%，强修正回退比例 29.95%。
- 2600 keV 邻域尖峰比为原公式的 0.9995 倍，没有新增 2600 keV 假峰。
- 全谱最坏局部尖峰增长为 1.0994，刚好低于 1.10 安全阈值，因此这一项仍然偏临界。
- Spearman 能量排序相关系数为 0.999968。
- 10 个时间块内修正中位数跨度为 0.0222%，时间稳定性通过。

## 结论

多变量确实提高了模型的适用覆盖率，并找到了数值上略优于 M06 的四变量候选；但分辨率增益相对 M06 很小，尚不能证明是真实、可重复的提升。当前 v15 应保留为研究候选，不应直接替换老师使用的模型。下一步必须使用新 run 和多个单能峰做盲测，尤其复查全谱局部尖峰增长接近阈值的问题。
