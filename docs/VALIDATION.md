# 验证边界与本次审查

## 科学结果的适用范围

1. **当前仍是探索性研究。** 时间匹配路线是在开发过程中观察高能 run 差异后继续探索的。虽然该步骤内的候选选择只读取 Kr，整套研究不能称为预注册的、全程未看过高能数据的盲测。
2. **两种交叉验证不同。** 全局方案留出 Kr run；时间匹配方案在同一局部时段内留出事件。后者不能证明跨时期泛化。
3. **预处理的折隔离需要进一步审查。** 时间匹配脚本先用完整局部峰窗计算每个 run 的信号中位数，再在训练折上拟合响应图。该步骤没有完全限定在训练折。归一化有可能在部分候选中抵消，但本次没有量化其影响；不能直接宣称所有预处理都已严格隔离。
4. **不确定性不是全链路的。** Bootstrap 重采样冻结的前后能量，不重新抽取 Kr、拟合响应图、选择模型或改变时段划分。
5. **拟合与过滤也会影响区间。** run 9566 仅保留 110/150 次迭代；峰拟合是固定区间的高斯加线性背景，未包含系统扫描或拟合优度验收。
6. **覆盖与绝对能标仍未解决。** P1 边界命中较多，所有修正后峰位仍偏离标称能量；需要补充低 dt Kr 和多峰能标。

这些限制在本轮整理中明确记录，历史脚本和证据没有被静默改写，因此现有结果仍可逐字节追溯。

## 本轮仓库改进检查

- 对原公开包逐文件检查，发现 **54 组完全相同的文件**；将完整快照保留在固定版本，主目录只保留当前阅读与运行所需内容。
- 核对结果 JSON 与实现，纠正“22.8% 全部达到下限”和“110 次全是成功拟合、其余全是失败”等不充分表述。
- 把点估计、条件 bootstrap 区间、峰位偏差及绝对 σ 分开展示。
- 增加输入合同检查、可运行合成数据示例、结构化运行记录，以及独立于第三方库的证据检查器。

具体运行记录见 [CHECKS.md](CHECKS.md)。本次检查证明整理后的程序入口和演示可运行，不构成新的物理验证。
