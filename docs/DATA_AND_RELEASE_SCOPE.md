# 数据与发布范围

本仓库是供公众理解研究工作的整理版，不是原工作目录的无差别镜像。原始本地文件未被修改。

## 已包含

- 现存的早期至 v21 分析代码、历史验证方案及候选运行程序。
- 可公开 PDF、LaTeX 源文件、研究说明和模型卡。
- 汇总指标、候选比较、bootstrap 汇总、诊断图和可读 JSON 模型参数。
- 研究路线、数据格式、复现说明、来源清单及公开文件 SHA-256 清单。

## 未包含

- 原始实验 ROOT/TXT 数据和逐事件 CSV/TSV/TXT 输出。
- 可能内嵌逐事件数据的交互 HTML。
- 二进制 `.joblib` 模型：保留对应源代码、模型卡和可读参数，避免把未经逐项审计的序列化内容公开。
- 原有 ZIP 压缩包：避免将内部路径、数据或旧运行环境随嵌套压缩包带出。
- SSH/服务器管理工具、权限设置、账号信息、缓存、Python 运行时、编译日志和重复的 PDF 渲染页。
- 含内部路径的 v13 PDF 副本；其路径已处理的 LaTeX 源文件及其他阶段报告仍保留。

路径中的本地用户名替换为 `researcher`；集群路径改为示例路径。历史 Markdown 顶部增加状态提示，说明“当前推荐”不代表整个项目的最新结论。

## 清单

- [原文件来源记录](source_inventory.json)：包含原文件哈希与公开副本是否调整。清单记录的是整理前后差异，不是完整原始工作目录的备份。
- [省略文件记录](excluded_files.json)：记录所选研究目录内省略的文件和理由；缓存等不属于研究成果的顶层目录没有逐项收录。
- [公开快照哈希](PUBLIC_MANIFEST.json)：由校验工具生成，记录除该清单本身和 `.git` 等本地缓存以外的全部公开文件。

如果旧材料引用了上述未公开文件，该引用用于追溯。请勿将缺少原始数据的公开包描述为完整数值复现，或将已废止的历史结果当作最新结论。

## 权利与研究状态

这是个人研究项目的材料整理，不代表 PandaX 合作组官方软件或正式发表结论。公开浏览不意味着授予实验原始数据访问权或第三方材料的再分发许可；当前未添加额外开源许可证。
